Regularized regression, visually

Charge the fit for large weights: why ridge, lasso and elastic net help, and what they do to the loss surface.

Why regularize? When features move together

Problem: two features that move together, like a house's floor area and its number of rooms. The data pin down their combined effect w1 + w2 but say little about how to split it, so OLS fits to fresh samples swing far along the line w1 + w2 = 6. On average OLS is right; any one fit can be far off.

Approach (ridge): charge (λ2/2)‖w‖2. Lopsided splits cost the most, so ridge pulls every fit toward an even split and toward 0: a little bias buys a large drop in variance.

Why regularize? When only a few features matter

Problem: which genes drive hair loss? A gene panel measures 2,000 genes per person, but lab work is expensive, so only 100 people are studied: 20 times more features than samples. Then infinitely many w fit every person exactly, all tied at the lowest possible training MSE, 0, so MSE alone cannot choose among them. OLS (the pseudo-inverse) reports the one with the smallest ‖w‖, which spreads the effect thinly over all 2,000 genes.

Approach (lasso): charge λ1‖w‖1. It pushes small weights to exactly 0, leaving a short list of genes to study: feature selection.

The loss surface: MSE plus a penalty

Goal: the w with the smallest J(w). With two features J is a surface over (w1, w2), and gradient descent walks down it as before.

J(w) = 12n ‖Xw − y‖2 + λ1 ‖w‖1 + λ22 ‖w‖22
∇J(w) = 1n X⊤(Xw − y) + λ1 sign(w) + λ2w w ← w − η ∇J(w)

sign(w) is taken entry by entry, with sign(0) = 0. |w| has no slope at 0, so this is a subgradient: it jumps from −λ1 to +λ1 as a weight crosses 0.

Why lasso zeros weights: the minimum w* (★) is where an MSE level set (teal) just touches a penalty level set (blue). The lasso diamond has corners on the axes, so the touch often lands on a corner, where one weight is exactly 0. Ridge's circle has no corners.

Try this

  • With OLS, slide Correlation from 0 up to 0.95. What happens to the cloud of fits?
    AnswerIt stretches along the line w1 + w2 = 6. The data still pin down the sum, but not how to split it, so any one fit can be far from the true w (×).
  • Switch to Ridge and raise λ2 to the ▼.
    AnswerThe cloud tightens toward an even split, and the error drops by more than half. Ridge gives up a little bias (the ♦ slides toward 0) for a large cut in variance.
  • Try Lasso instead.
    AnswerThe cloud slides toward 0 without tightening, so the error only rises. Lasso is for weights that should be 0; here both features matter.
  • At λ1 = 0 (OLS), compare the training and test-set MSE.
    AnswerTraining MSE is 0, but test-set MSE is barely better than predicting 0 for everyone. OLS memorized the 100 people.
  • Raise λ1 until only a handful of stems remain. Which genes survive?
    AnswerThe 4 that matter (red ticks mark their true weights), and test-set MSE falls more than tenfold. That short list is what the lab wanted: 4 genes to study, not 2,000.
  • Now switch to Ridge and raise λ2.
    AnswerEvery weight shrinks but none reaches 0, so there is no short list, and test-set MSE stays near OLS's.
  • With Ridge, raise λ2 and follow ★ along the path.
    Answer★ slides from OLS toward 0, always where an MSE ellipse touches a circle. Both weights shrink; neither reaches 0.
  • Switch to Lasso and raise λ1 from 0.
    AnswerAlmost at once ★ lands on the w1 axis, at the diamond's corner, and w2* is exactly 0. The true w2 is 0, and lasso finds it.
  • With Lasso, press Run.
    AnswerGradient descent reaches the axis, then zig-zags across it: sign(w2) flips every step, so w2 never lands on exactly 0, and Run stops at the step cap.
